# sequential-interaction-project-2
Code base for my sequential interaction in IXD: Code and Form working with Claude Code

## Flower Shop sequence prototype

A single, continuous interaction built from the three studies: pick a bouquet, ring the bell, pay at the till.
The site is in `docs/`, and `SEQUENCE.md` describes the decisions, the steps and the files.

To publish it, go to Settings → Pages, choose Deploy from a branch → `main` → `/docs`. It is then live at
https://xwen2-lgtm.github.io/sequential-interaction-project-2/
